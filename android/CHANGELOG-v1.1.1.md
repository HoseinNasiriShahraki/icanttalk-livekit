# iCANTtalk Android v1.1.1

- Fixed remote profile pictures by reading each participant's metadata.
- Added stable identity-based fallback avatars for legacy tokens.
- Removed the fullscreen username/title bar.
- Added a transparent floating close control.
- Forced fullscreen media to aspect-fit and disabled hardware scaling in fit mode to avoid portrait/rotation cropping.
- Added a clearer room-preview error when Django has not been upgraded.
- Fixed PowerShell Java-version detection when `java -version` writes to stderr.
