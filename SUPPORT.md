# Support

Use GitHub Issues for reproducible bugs and feature requests. Include the platform, app version, operating-system version, expected behavior, actual behavior, and sanitized logs.

Do not post API keys, access keys, participant tokens, private endpoints, personal information, or signing credentials.

For deployment questions, read:

- `docs/DEPLOYMENT.md`
- `docs/TROUBLESHOOTING.md`
- `server/django/README.md`
