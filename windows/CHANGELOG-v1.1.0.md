# iCANTTalk v1.1.0 changelog

## Added

- Per-stream start/stop watching for webcams and screen shares.
- Concurrent multi-stream viewing.
- Screen-share audio mute and volume controls.
- Fullscreen media.
- Portrait camera layout support.
- Taskbar-safe Windows call controls.
- Room participant previews before joining.
- Krisp enhanced microphone filtering option.
- Random/default profile picture pool and settings picker.
- New application icon.
- Shared Windows/Android participant metadata.
- Django presence operation and short presence cache.

## Compatibility

The Windows and Android clients remain compatible by using the same LiveKit project, endpoint, access key, and room names. Deploy the included Django endpoint before installing either updated client.
